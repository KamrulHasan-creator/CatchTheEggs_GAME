# CatchTheEggs_GAME
# 🥚 Catch The Eggs Game

A simple 2D arcade game built with **Python** and **Pygame**, where the player controls a basket to catch falling eggs and score points.

## 🚀 Features

* 🧺 Move basket using arrow keys (← →)
* 🥚 Random falling eggs
* 🎯 Score system
* ❌ Game Over condition
* ⚡ Simple and smooth gameplay

---

## 🛠️ Built With

* Python 🐍
* Pygame 🎮

## 📦 Installation

### 1. Install Python

Download from:
https://www.python.org/downloads/

### 2. Install Pygame

```bash id="p1"
pip install pygame-ce
```

---

## ▶️ How to Run

Use the following command to run the game:

```bash id="p2"
py -3.14 catch.py
```

or (alternative):

```bash id="p3"
python catch.py
```

---

## 🎮 Controls

* ⬅️ Move Left
* ➡️ Move Right

---

## 🧠 Game Logic

* Eggs fall from top randomly
* Player must catch them using basket
* Each successful catch increases score
* Missing an egg ends the game
